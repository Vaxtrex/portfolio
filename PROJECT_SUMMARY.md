## 🐛 Troubleshooting

| Issue | Solution |
|-------|----------|
| Pages won't turn | Drag from right edge of page, not center |
| Photos not uploading | Check browser console, ensure file format supported |
| Slow on mobile | Reduce photos per page, compress images |
| Animations jerky | Check browser hardware acceleration, close other tabs |
