## 🎯 Quick Customization

### **Change Cover Title**
1. Open `index.html` in text editor
2. Find line with `<h1>Memories</h1>`
3. Change to `<h1>Your Title</h1>`
4. Refresh browser

### **Change Colors**
1. Open `THEME_CUSTOMIZER.html` in browser
2. Adjust color sliders
3. Copy the CSS code
4. Paste into `styles.css`

### **Change Animation Speed**
1. Open `script.js` in text editor
2. Find `turnDuration: 600`
3. Change number (smaller = faster)
4. Refresh browser

### **Add Different Photos**
1. In `script.js`, find the `photos` array
2. Replace URLs with your own image links
3. Refresh browser

## 🆘 Something Not Working?

### **Can't open index.html?**
→ Double-click it, or right-click → Open with Browser

### **Pages won't turn?**
→ Drag from the RIGHT EDGE of the page (not the center)

### **Photos not showing?**
→ Check browser console (F12), look for errors

### **Animations are slow?**
→ Reduce number of photos per page in config

### **Need help?**
→ Read `QUICK_REFERENCE.md` or `README.md`

## 💡 Pro Tips

1. **Use Square Images** (1:1 aspect ratio) for best results
2. **Compress Images** with TinyPNG before uploading
3. **Test on Phone** for best mobile experience
4. **Use Light HTTPS URLs** for all images
5. **Browser Cache** - Clear cache if changes don't show
